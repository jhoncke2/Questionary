# 🎮 Questionary

Questionary es un juego de preguntas de selección múltiple desarrollado en Kotlin para Android.
El objetivo del juego es responder correctamente una cantidad mínima de preguntas para ganar. Si el jugador no alcanza ese puntaje, pierde la partida.

El juego cuenta con una interfaz sencilla, un ícono y una canción de fondo divertida que acompaña la experiencia del usuario.

---

## 📱 Características

- Preguntas de selección múltiple
- Sistema de respuestas correctas e incorrectas
- Condición de victoria basada en el número de aciertos
- Pantalla de derrota si no se alcanza el puntaje mínimo
- Música de fondo durante el juego
- Desarrollado en Kotlin para Android

---

## 🛠️ Tecnologías

- Kotlin
- Android SDK
- Android Studio
